HTSTCL-GNN Architecture

Hierarchical Spatio-Temporal Contrastive Learning

PyTorch 2.10
01

Spatial Graph Encoder (GAT)

Constructs k-NN flow graphs (k=2) and utilizes 4-head Graph Attention to capture node-level correlations across 91 flow features.

02

Temporal Encoder (Bi-GRU)

Processes sliding sequences of 5 consecutive temporal graphs to detect time-series attack progression and low-rate anomalies.

03

Hierarchical Cross-Modal Fusion

Multi-head self-attention fuses spatial graph embeddings and temporal dynamics into an unified 128-dimensional latent representation.

04

Self-Supervised Contrastive Learning

Trained with hybrid InfoNCE contrastive loss and weighted cross-entropy for superior boundary separation on unbalanced traffic.

File Requirement Details

Data formatting guidelines for GNN processing

Sample CSV

91 Numerical Flow Features

Columns must match the trained model's feature space (duration, packet counts, byte volumes, load, rates, TCP flags, protocols, and QoS DSCP slicing).

Window & Sequence Grouping

Flows are grouped into windows of $W=5$ records to construct k-NN topological graphs, and consecutive windows form 5-graph temporal sequences.

Missing Value & Header Handling

Any missing headers or null/NaN cells are automatically imputed with zero and globally normalized via standard deviation scaling.

Ground Truth Columns (Optional)

Columns Label and Attack Type (e.g. SYNScan) are optional. If present, the engine compares ML detections with ground truth.
